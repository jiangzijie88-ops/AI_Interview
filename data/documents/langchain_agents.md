# LangChain：Agent 工具循环与终止

> 整理日期：2026-11-12；性质：官方资料的非官方中文归纳，含教学示例与误区说明。

## Agent 是什么
Agent 通常是模型与工具组成的循环：模型判断下一步、提出工具调用，应用执行并返回结果，模型继续判断，直到任务完成或触及限制。
## 与固定链的区别
固定链的步骤主要由开发者决定。Agent 能根据输入动态选择工具和执行顺序，灵活性更强，但成本、延迟与行为也更难预测。
## 工程约束
明确目标、可用工具、允许访问的数据、终止条件和调用预算。工具报错后应反馈可理解的信息，避免无限重复同一失败操作。
## 项目应用
主点评按固定“检索 → 生成 → 保存”执行，没必要为学习 Agent 就改成自由工具循环。需要动态检索多个来源、比较证据时，可再评估 Agent。
## 常见误区
调用一次聊天模型不等于 Agent；使用 LangGraph 也不自动等于自主 Agent。模型决定与真实副作用之间必须有后端检查。
## 自测问题
哪些步骤由程序决定，哪些由模型决定？如何判断任务结束？
