# LangChain：工具定义、参数与执行权限

> 来源：https://docs.langchain.com/oss/python/langchain/tools
> 范围：LangChain Python 在线文档
> 整理日期：2026-11-12；性质：官方资料的非官方中文归纳，含教学示例与误区说明。

## 工具的职责
工具是供模型请求执行的功能，通常由 Python 函数、名称、描述和参数 schema 组成。类型注解与说明帮助模型构造参数，应用代码才真正执行功能。
## 工具调用流程
模型提出调用 → 应用检查参数及权限 → 执行函数 → 返回工具结果 → 模型继续处理。模型输出工具参数不等于操作已经执行。
## 实际设计
工具应有明确、较小的业务职责。查询工具与有副作用的写入工具分开。用户身份、权限上下文应由后端可信环境提供，不能完全信任模型自行填写的 user_id。
## 项目应用
“查询参考资料”可以封装为工具；但当前项目是在 manager 中固定调用检索服务，并没有让模型自主决定调用。这是两种不同编排方式。
## 常见误区
工具 schema 校验不替代业务授权。执行付款、删除、发送消息等操作还需具体权限、幂等和失败处理；给模型绑定工具不代表它能安全执行所有动作。
