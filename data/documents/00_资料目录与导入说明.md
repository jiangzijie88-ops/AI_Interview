# 官方资料中文归纳目录

整理日期：2026-11-12。本批新增 48 份按主题划分的中文资料，来源为官方文档或官方源码。它们是选择性归纳，非官方逐字翻译；工程示例和误区为教学说明。原有 langgraph_interrupts.md 保留。

## 导入与使用

- 本目录文件不会自动进入数据库；在管理员新增资料表单逐份选择 MD 文件，填写标题、来源和版本说明。保存后检查、审核，再重建索引。
- 本目录文件均为 UTF-8，单篇少于 10000 字符。不要把本目录说明文件当成知识正文导入；JSON 不是当前上传格式。
- Python 资料优先按项目使用的 3.11 文档整理；SQLAlchemy 为 2.0，Pydantic 为 v2 风格，MySQL 文档为 8.4，运行实例若为其他版本应核对。
- LangChain / LangGraph 在线文档更新快，新 Agent 或事件流 API 不一定适用于本地版本，不能为导入资料就替换现有代码。
- 首批可先导入 graph_basics、state_reducers、persistence、runnable_lcel、structured_output、fastapi_async、dependencies、sqlalchemy_session。
- sources 链接与版本说明也写在每篇正文内，但表单不会自动解析元数据，需要另填。保存来源日期，更新资料后重新审核并重建。
- 距离阈值 1.2 仅为现有少量样例试验值；语料扩充后应使用相关和无关问题重新检查，不能保证准确率。
- 涉及安全、事务或高级并发时，这些短篇用于建立基本认识；生产实现仍需阅读全文并验证。
