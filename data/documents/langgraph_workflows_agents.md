# LangGraph：固定工作流与自主 Agent 的选择

> 来源：https://docs.langchain.com/oss/python/langgraph/workflows-agents
> 范围：LangGraph Python 工作流模式
> 整理日期：2026-11-12；性质：官方资料的非官方中文归纳，含教学示例与误区说明。

## 两类控制方式
工作流主要沿开发者规定的路径运行。Agent 根据输入与工具结果动态决定下一步，适用于路径不容易预先穷举的任务。
## 常见模式
顺序调用将任务拆成阶段；路由将不同输入分发到不同处理路径；并行模式独立处理子任务；评估与改进循环根据反馈继续修正。
## 选择原则
能用简单固定流程稳定解决的问题，优先显式步骤。需要模型动态决策时，再增加 Agent 循环，同时设置终止与工具权限边界。
## 项目应用
面试系统“点评 → 等用户选择 → 追问 → 等回答 → 点评”非常适合显式工作流；资料检索也可作为固定服务步骤，不必强行增加模型决策。
## 常见误区
多节点图不一定是多 Agent；多次模型调用也不等于自主规划。循环要有质量判断与次数边界，不能仅靠更长提示词。
