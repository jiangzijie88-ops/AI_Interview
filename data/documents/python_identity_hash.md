# Python：对象身份、相等性、可变性与哈希

> 来源：https://docs.python.org/3.11/reference/datamodel.html
> 范围：Python 3.11
> 整理日期：2026-11-12；性质：官方资料的非官方中文归纳，含教学示例与误区说明。

## 身份与值
对象具有身份、类型和值。is 比较是否同一个对象；== 比较相等性，其具体行为可由类型定制。两个内容相同的列表可以相等但不是同一对象。
## 可变性
列表可以原地修改。元组不能替换槽位中的引用，但其中若包含列表，仍可修改列表内部内容。不可变容器不等于引用的所有对象都不可变。
## 哈希约束
可哈希对象应在生命周期内保持哈希值稳定，相等对象必须有相同哈希值。并非所有元组都可哈希：包含列表的元组不可作为字典键。
## None 判断
通常使用 x is None 或 x is not None，避免相等性定制干扰。if not x 还会匹配 0、空容器等其他假值。
## 自写示例
a=[1]; b=[1]; c=a。a==b 为真，a is b 为假，a is c 为真。不能用整数缓存、字符串驻留推导一般的数值相等规则。
