# 前端导航与视觉整理

已获用户批准：保留 Streamlit，采用左侧导航、浅色蓝白主题、用户与管理员功能分区。仅修改前端。

## 文件和步骤

1. frontend/ui.py 与 .streamlit/config.toml：统一主题、状态中文名称和页面说明。
2. frontend/app.py：侧栏导航、登录注册切换、个人主页、按角色显示管理入口；练习详情独立渲染。
3. frontend/interview.py：创建表单三列、创建后跳转详情、列表进入详情、答题进度、题号换行；保留草稿和提交机制。
4. frontend/question_admin.py：抽取列表、详情、审核、新增子视图，按所选入口调用，不同时执行所有表单。
5. frontend/document_admin.py：分为列表维护、新增导入、索引检索；长正文折叠，检索默认显示摘要。
6. AST 语法检查和 Streamlit AppTest 模拟 HTTP 验证：未登录、普通用户、管理员、详情返回、创建跳转、表单及草稿；不调用真实模型，不修改数据库。

## 验收

- 普通用户无法通过页面状态进入管理视图；后端原权限检查不变。
- 导航切换不把不同业务堆叠；个人主页保留退出登录。
- 旧请求路径与正文契约保留，状态、难度以中文展示但提交英文值。
- 测试通过后仅报告实际验证范围，不声称完成真实后端端到端验证。
